# Documents mode

Use this mode for reports, slides, spreadsheets, PDFs, research and other
business writing.

## Clues

The task is documents work when one or more of these is true:

- **Location:** there is no code repository, or the folder holds only document and data files.
- **Request words:** report, slides, deck, spreadsheet, PDF, memo, research, email, proposal (and close variants: presentation, summary, letter, table, chart, brief).
- **File types mentioned or present:** `.docx`, `.pptx`, `.xlsx`, `.pdf`, `.csv`.

## Preferred skills

| Kind of work | Preferred skill |
|---|---|
| Reports, memos, proposals, letters | docs |
| Slides and decks | pptx (or a slides artifact type, if available) |
| Spreadsheets and tables | xlsx |
| Reading or making PDF files | pdf |
| Charts and graphs | data visualization (e.g. `dataviz`) |

These names are hints, not requirements. Read the list of skills that are
actually installed and use the closest installed match for each kind of work.
If nothing installed comes close, follow `../features/new-skills.md`.

## Conflict rule

In documents mode, when two skills disagree, the format or template the user
asked for wins. For example, if the user asked for slides, the slides skill's
rules beat a general writing skill's rules.
